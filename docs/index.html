Agent skill · one Python CLI

Generated art in. Game‑ready sprites out.

An image model draws the sheet. sprite.py plans the prompt, cuts out and registers every frame, packs the atlas, writes a review page and tells you which frames to redraw.

Quick start View on GitHub
  • any image model
  • no provider keys in the CLI
  • Pillow + numpy + scipy

Each fighter: one generated sheet, every state in it.

Workflow

Draw it once. Repair only what broke.

Frames drawn in one image share light, color and scale. So the whole sheet is generated first, checked, and only the frames that fail are redrawn from their healthy neighbors.

Healthy sheets

        
Every frame that broke gets a name.

        
Checks catch missing frames, size jumps, light shifts, cut-off poses and matte halos. repair writes a kit for each bad frame from its nearest healthy neighbors, and --patch drops the redraw back in at the right size.

      

      

        
        
      

      

        

          

            
            

          

          
Demo input: the four faults were injected into a real generated sheet. The repairs are real generations from the repair kits.

        

        

      

      

        
repair --frame 2 --frame 3 …Each kit holds the nearest frames that are not broken, the pose guide and a prompt.

        
generate the in-betweenSame character, same light; only the pose comes from the guide.

        
build --patch punch:3=…The patch is scaled to its neighbors' body size; checks run again.

      

    

  


  

    

      

        
Install

        
Clone it. Point your agent at it.

        
    
          
  • Python 3.11+ with Pillow, numpy and scipy.
    • 
          
  • Any image model. The agent generates; the CLI never calls a provider or holds a key.
    • 
          
  • Optional: rembg[cpu] for BiRefNet cutouts on busy backgrounds.
    • 
          
  • Status: animation, slots and atlas are ready. Tiles and backgrounds come next.
    • 
        

      

      
# get the skill
git clone https://github.com/gvastethecreator/spritesheet-expert-skill
cd spritesheet-expert-skill/v2/spritesheet-expert

# plan a run, generate prompts/_all.txt with your model, then:
python sprite.py plan --out runs/hero --subject "a vinyl-toy fighter" \
  --anchor hero.png --state idle:4 --state punch:6:attack:12
python sprite.py build runs/hero --source all=sheet.png --provider "my model"
python sprite.py check runs/hero --strict
