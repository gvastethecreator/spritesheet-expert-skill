Agent skills · 2D game assets

Generated art in. Checked game assets out.

Six agent skills for 2D game art. An image model draws the art. The skills cut it out, register frames, pack atlases, validate each delivery and record where every source came from. They never paint replacement art.

Install View on GitHub
  • Python 3.11+
  • Pillow + jsonschema
  • no provider keys
# loose items in, packed atlas and review page out
python scripts/run_item_atlas_workflow.py items.png \
  --output-dir runs/items --models none

# which lane is this, and what is its final gate?
python scripts/check_workflow.py \
  --run-dir runs/items --describe

Run from the installed spritesheet-expert folder. The final gate for this run is validate_item_delivery.py.

Skills

One skill per asset family.

Use the narrowest skill that owns the asset. Each folder runs on its own. Pick one to see the command your agent runs and what it writes.


    

  


  

    

      

        
Sprite lanes

        
Four lanes, one final gate each.

        
spritesheet-expert picks a lane from the source and the result you ask for, not from the file extension. Each lane ends at its own validator.

      

      

        

          
static-items · gate validate_item_delivery.py

          
Irregular items

          
Loose items on one sheet become separate items packed into atlas pages. Every visible pixel is assigned once, left pending or explicitly discarded. The packer never rotates or scales an item to fit.

        

        

          
true-grid · gate validate_run.py

          
Exact grids

          
Exact slots or a non-animated variant set, such as a set of character poses. Fixed cells need a true grid; otherwise the source boxes are detected and inspected.

        

        

          
animation · gate validate_run.py

          
Animation rows and video frames

          
Frames are registered to an explicit runtime cell and pivot. Existing videos go through frame selection first. Proof is playback, a contact sheet, onion skin and identity.

        

        

          
tileset · gate validate_run.py

          
Tiles and textures

          
Adjacent tiles and repeat textures, including isometric sets. Proof covers repeat and adjacency, projection, pivots and the map.

        

      

    

  


  

    

      

        
Rules

        
Models draw. Code checks.

        
Every skill keeps the same production rules.

      

      

        
No replacement artScripts prepare, extract, register, cut out, compose, preview and validate. They never create replacement production art.

        
Native alpha firstValid provider transparency is kept. A gray, black or white matte is the fallback; new sources never use chroma green, blue, cyan or magenta.

        
A record for every sourceEach source declares its provider or import provenance, and its hash is pinned.

        
Fixtures are not artA fixture can pass validation, but it never counts as representative production media.

        
Proof matches the assetPlayback and onion skin for animation, composite and scroll for backgrounds, state and stretch boards for UI.

        
Validated is not engine-testedCheck the real engine loader, texture limits, filtering and pivots before calling an asset engine-ready.

      

    

  


  

    

      

        
Install

        
Copy a folder. Point your agent at it.

        
    
          
  • Python 3.11+. Each skill ships its own pinned requirements: Pillow and jsonschema, or jsonschema alone.
    • 
          
  • Your image tool. Imagegen by default. Grok Imagine only when you select it, with a dry run before a paid run.
    • 
          
  • Optional: video frame intake, rembg cutouts and a locked Lucida/BEN2 model runtime in spritesheet-expert.
    • 
          
  • Multi-family packs: produce-2d-assets bundles all five family workflows.
    • 
        

      

      
# get the skills
git clone https://github.com/gvastethecreator/spritesheet-expert-skill
cp -r spritesheet-expert-skill/SKILLS/spritesheet-expert <your-agent-skills-folder>/

# or with the skills.sh CLI
npx skills add gvastethecreator/spritesheet-expert-skill

# runtime for spritesheet-expert, from its folder
python -m pip install -r scripts/requirements-core.txt

# runtime for the other five, from each folder
python -m pip install -r requirements-runtime.txt
