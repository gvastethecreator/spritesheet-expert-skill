For Codex, Claude Code, and any agent that runs skills

Generated art in. Game‑ready sprites out.

An image model draws. These skills do everything after: cut exact pixels, register frames, pack atlases, check motion and identity, and keep a receipt for every file.

Install
npx skills add gvastethecreator/spritesheet-expert-skill

Six skills. Python 3.11+. Image provider of your choice.

      Install

      Pick the narrowest skill that owns the asset.

      • spritesheet-expertItem atlases, animation rows, pose sets, VFX, tilesets, video frames
      • build-static-game-assetsProps, pickups, decals, item packs
      • build-game-backgroundsLayered, scrolling, parallax backgrounds
      • build-game-ui-kitsUI states, densities, nine-slice assets
      • compose-asset-mockupsLabeled presentation boards from validated assets
      • produce-2d-assetsDeliveries that span several families
